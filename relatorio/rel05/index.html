1 Introdução

A aproximação de distribuições discretas (como a Binomial e a Poisson) pela distribuição Normal (contínua) é um dos resultados mais elegantes e práticos da estatística. Esse fenômeno é fundamentado pelo Teorema Central do Limite (TCL) e pelo Teorema de de Moivre-Laplace.

Neste relatório, vamos entender como essas aproximações funcionam, as demonstrações matemáticas (usando Funções Geradoras de Momentos) e as aplicações práticas com a necessária correção de continuidade.

3 Por que usar a aproximação Normal?

Historicamente, antes dos computadores, calcular a distribuição Binomial \(P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}\) para um “n” grande era inviável. A Normal oferecia tabelas acessíveis. Hoje, a aproximação ainda é útil porque:

  • Simplifica demonstrações teóricas em estatística inferencial;

  • Fundamenta testes e intervalos de confiança (ex.: teste Z para proporções);

  • Oferece intuição geométrica sobre a forma das distribuições;

  • Em contextos de grande volume de dados, os resultados assintóticos valem plenamente.

  • Sem a aproximação: É uma conta absurdamente longa (e que antigamente, antes dos computadores, era simplesmente impossível de fazer à mão).

  • Com a aproximação Normal: Você calcula a média, o desvio padrão e faz uma única conta rápida usando a tabela Z (ou uma linha de código).

Em resumo, a medida que os parâmetros crescem \(n→∞\) \(ou\) \(λ→∞\), tanto a Binomial quanto a Poisson “perdem” sua assimetria e se tornam indistinguíveis de uma curva Normal com mesma média e variância, uma manifestação elegante do Teorema Central do Limite.

4 Teorema Central do Limite

O ponto de partida segundo Durrett (2019) é o Teorema Central do Limite (TCL) ou Teorema do Limite Central(TLC), que afirma que a soma (ou média) de um grande número de variáveis aleatórias independentes e identicamente distribuídas tende a uma distribuição Normal, independentemente da distribuição original.

Dadas \(n\) variáveis aleatórias independentes \(X1,X2,…,Xn\), todas com a mesma distribuição, média \(μ\) e variância \(σ²\) finitas, a soma (ou média) dessas variáveis, quando \(n→∞n\) converge em distribuição para uma Normal:

\[\bar{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)\] Equivalentemente, a variável padronizada:

\[Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1)\] O resultado notável é que isso vale independentemente da distribuição original de cada \(Xi\) — seja ela discreta, contínua, assimétrica ou multimodal.

Algumas condições para que Teorema do Limite Central (TLC) possa ser aplicado:

  • As variáveis devem ser independentes entre si.

  • Cada variável deve ter média \(μ\) e variância \(σ²\) finitas.

  • O número de observações \(n\) deve ser suficientemente grande, em geral \(n≥30\) é uma regra prática, embora isso dependa da forma da distribuição original.

Conforme somamos mais variáveis aleatórias independentes, a distribuição da soma vai se “suavizando” e se tornando cada vez mais simétrica e em forma de sino — a curva normal. Distribuições muito assimétricas exigem um nn n maior para que a aproximação seja boa.

O Teorema Central do Limite (TCL) justifica o uso generalizado da distribuição normal em estatística:

  • Inferência estatística: médias amostrais são aproximadamente normais para amostras grandes, o que sustenta intervalos de confiança e testes de hipótese.
  • Controle de qualidade: médias de processos produtivos seguem distribuições aproximadamente normais.
  • Ciências naturais e sociais: fenômenos que resultam da soma de muitos fatores independentes tendem a ser normalmente distribuídos (altura, erros de medição, etc.).

5 Aproximação da distribuição Binomial à Normal

A distribuição binomial \(B(n,p)\) descreve o número de sucessos em \(n\) ensaios independentes, cada um com probabilidade \(p\) de sucesso. Quando \(n\) é suficientemente grande, calcular probabilidades binomiais exatas torna-se trabalhoso — o fatorial de números grandes é computacionalmente custoso. É nesse contexto que surge a aproximação pela distribuição normal: pelo Teorema Central do Limite, a soma de muitas variáveis aleatórias independentes e identicamente distribuídas tende a uma distribuição normal, e a binomial é exatamente isso — a soma de \(n\) variáveis de Bernoulli. Assim, para \(n\) grande, \(B(n,p)\) se comporta como uma normal \(N(μ,σ2)\), com média \(μ=np\) e desvio padrão \(σ\):

\[\sigma = \sqrt{np(1-p)}\]

Para aplicar a aproximação, a regra prática mais comum exige que \(np≥5\) e \(n(1−p)≥5\) — sendo que muitos autores preferem o critério mais conservador de \(np≥10\) e \(n(1−p)≥10\) para garantir boa precisão. Satisfeita essa condição, calcula-se \(μ\) e \(σ\), padroniza-se a variável com \(Z=(X−μ)/σ\) e consulta-se a tabela da normal padrão. Como a binomial é discreta e a normal é contínua, recomenda-se aplicar a correção de continuidade:

Ao calcular \(P(X=k)\) usa-se \(P(k−0,5≤X≤k+0,5)\) para \(P(X≤k)\), usa-se \(P(X≤k+0,5)\) e para \(P(X≥k)\) usa-se \(P(X≥k−0,5)\). Essa correção reduz o erro introduzido pela transição do discreto para o contínuo.

A qualidade da aproximação depende diretamente de \(n\) e de quão próximo \(p\) está de \(0,5\). Quando \(p\) é próximo de \(0,5\), a binomial já é simétrica e a curva normal se ajusta bem mesmo para nn n moderados. Quando \(p\) é extremo — próximo de \(0\) ou de \(1\) — a binomial é muito assimétrica e são necessários valores de \(n\) muito maiores para que a aproximação seja adequada.

Nesses casos extremos, pode ser preferível usar a aproximação de Poisson (para um \(p\) pequeno e \(n\) grande) em vez da normal. No geral, a aproximação normal é uma ferramenta poderosa e prática, amplamente usada em inferência estatística, intervalos de confiança e testes de hipóteses para proporções.

5.1 Exemplo de aplicação

Controle de Qualidade em uma Fábrica

Uma fábrica produz peças e sabe, por histórico, que 5% das peças são defeituosas. Em um lote de 200 peças, qual a probabilidade de encontrar mais de 15 peças defeituosas?

Passo 1 — Identificar o modelo:

\(X∼B (n=200\), \(p=0,05)\)

Obs: Calcular isso exatamente exigiria somar 185 termos binomiais. Usaremos a aproximação normal.

Passo 2 — Verificar a condição de validade:

\[np=200×0,05 = 10 (≥5)\] (Satisfaz)

\[n(1−p)=200×0,95=190 (≥5)\] (Satisfaz)

Passo 3 — Calcular a média μ e desvio padrão σ:

\[μ=np=10\]

\[\sigma = \sqrt{np(1 - p)}\] \[\sigma = \sqrt{200 * 0,05 * 0,95}\] \[\sigma = \sqrt{9,5}\] \[\sigma \approx 3,08\]

Passo 4 — Aplicar a correção de continuidade:

Como queremos \(P(X>15)\), isso equivale a \(P(X≥16)\), então usamos \(15,5\):

\[P(X>15)≈P(Z>3,08155−10​)=P(Z>1,786)\]

Passo 5 — Consultar a tabela normal:

Podemos usar a Tabela Normal Padrão, disponível no Guru (2026) para consultar os valores:

\[P(Z>1,786)=1−Φ(1,786)≈1−0,9629=0,0371\]

Conclusão:

Há aproximadamente \(3,7\)% de chance de o lote conter mais de 15 peças defeituosas. Se esse risco for inaceitável para a fábrica, pode-se usar esse resultado para definir um plano de inspeção ou acionar um alerta de qualidade.

O valor exato pela binomial é ≈ \(3,9%\) — a aproximação ficou muito próxima, com erro inferior a \(0,2\) pontos percentuais.

6 Aproximação da distribuição de Poisson à Normal

A distribuição de Poisson \(P(λ)\) modela o número de ocorrências de um evento em um intervalo fixo de tempo ou espaço, onde \(λ\) representa a taxa média de ocorrências. Para valores pequenos de \(λ\), a distribuição é assimétrica e os cálculos exatos são viáveis. Porém, à medida que \(λ\) cresce, a distribuição vai se tornando cada vez mais simétrica e com formato de sino — exatamente o comportamento de uma normal. Isso ocorre porque a Poisson pode ser interpretada como a soma de muitas variáveis aleatórias independentes de Poisson com taxas pequenas, e pelo Teorema Central do Limite (TCL) essa soma converge para uma distribuição normal. Assim, para \(λ\) suficientemente grande, \(P(λ)\) se comporta como \(N(μ,σ²)\), com a elegante propriedade de que média e variância coincidem: \(μ=λ\) e \(σ²=λ\).

Para aplicar a aproximação, a condição geralmente exigida é \(λ≥10\) — quanto maior \(λ\), melhor o ajuste. Com essa condição satisfeita, calcula-se \(μ=λ\) e \(σ=λ\), padroniza-se com \(Z=(X−λ)/λ\) e consulta-se a tabela da normal padrão.

Assim como na aproximação da binomial, aplica-se a correção de continuidade, pois a Poisson é discreta e a normal é contínua: para \(P(X=k)\) usa-se \(P(k−0,5≤X≤k+0,5)\); para \(P(X≤k)\); usa-se \(P(X≤k+0,5)\); e para \(P(X≥k)\); usa-se \(P(X≥k−0,5)\). Essa correção melhora consideravelmente a precisão, especialmente para \(λ\) próximo do limiar mínimo.

A grande vantagem prática dessa aproximação está na simplificação dos cálculos: probabilidades acumuladas de Poisson para \(λ\) grande envolvem somas de muitos termos com exponenciais e fatoriais, enquanto a normal reduz tudo a uma única padronização e consulta de tabela. A aproximação é especialmente útil em áreas como epidemiologia (número de casos de uma doença), telecomunicações (chegada de chamadas em uma central), controle de qualidade (defeitos por unidade produzida) e física (decaimento radioativo). Vale lembrar que, diferentemente da binomial, a Poisson não tem um nn n explícito — a aproximação depende exclusivamente do valor de \(λ\), o que torna o critério de validade ainda mais simples de verificar.

6.1 Exemplo de aplicação

Central Telefônica

Uma central telefônica recebe, em média, \(λ = 25\) chamadas por minuto. Qual a probabilidade de receber entre \(20\) e \(30\) chamadas em um determinado minuto?

Passo 1 — Identificar o modelo:

\(X∼P(λ=25)\)

Obs: Calcular isso exatamente exigiria somar 11 termos com exponenciais e fatoriais grandes. Usamos a aproximação normal.

Passo 2 — Verificar a condição de validade:

\[λ=25≥10\] (Satisfaz)

Passo 3 — Calcular a média μ e desvio padrão σ:

\[μ=λ=25\] \[\sigma = \sqrt{λ}\] \[\sigma = \sqrt{25}\] \[\sigma = 5 \] Passo 4 — Aplicar a correção de continuidade:

Como queremos \(P(20≤X≤30)\), expandimos meio ponto em cada extremo:

\[P(20 \le X \le 30) \approx P\left( \frac{19,5 - 25}{5} \le Z \le \frac{30,5 - 25}{5} \right)\]

\[=P(−1,10≤Z≤1,10)\]

Passo 5 — Consultar a tabela normal:

Consultando na tabela normal padrão, temos:

\[P(−1,10≤Z≤1,10)=Φ(1,10)−Φ(−1,10)\]

\[=0,8643−0,1357=0,7286\] Conclusão

Há aproximadamente 72,9% de chance de a central receber entre 20 e 30 chamadas em um minuto. Esse resultado pode ser usado para dimensionar o número de atendentes necessários — garantindo, por exemplo, que em pelo menos 70% dos minutos a equipe consiga atender toda a demanda sem sobrecarga.

O valor exato pela Poisson é ≈72,4% — a aproximação ficou a menos de 0,5 ponto percentual do valor real, demonstrando excelente precisão.

Resistência do concreto

Um laboratório de controle tecnológico ensaia corpos de prova de concreto de uma obra. Com base em dados históricos, sabe-se que a probabilidade de um corpo de prova não atingir a resistência característica \(fck\) é de 12%. Em uma concretagem, são coletados 150 corpos de prova. Qual é a probabilidade de que mais de 25 deles apresentem resistência abaixo do \(fck\)?

Passo 1 — Modelagem e verificação:

X = (Número de Corpos de prova não adequados) ~ \(B(150;0,12)\)

\[np=150×0,12=18≥5\] (Satisfaz)

\[n(1−p)=150×0,88=132≥5\] A aproximação pela Normal é válida.

(Satisfaz)

Passo 2 — Parâmetros da Normal equivalente:

\[μ=np=18\]

\[σ=\sqrt{np(1−p)}\]

\[σ=\sqrt{150 * 0,12 * 0,88} \] \[σ=\sqrt{15,84}\] \[σ \approx 3,980 \] Passo 3 — Correção de continuidade:

\(P(X>25)\) é discreta, logo usamos \(P(Y>25,5)\) na Normal.

Passo 4 — Padronização:

\[Z = \frac{25,5 - 18}{3,980} = \frac{7,5}{3,980}\approx 1,884\]

Passo 5 — Cálculo da probabilidade:

\[P(X>25)≈P(Z>1,884)=1−Φ(1,884)=1−0,9702=0,0298\] Interpretção do engenheiro

Existe aproximadamente 3,0% de chance de mais de 25 corpos de prova não serem adequados. Segundo a ABNT NBR 12655, se essa probabilidade ultrapassasse 10% seria um sinal de alerta para revisão do traço do concreto — neste caso, o lote está dentro do aceitável.

7.2 Aproximação da distribuição de Poisson à Normal

Hidráulica urbana

Em uma rede de drenagem urbana, o número de ocorrências de alagamentos em um bairro segue uma distribuição de Poisson com média de 20 alagamentos por ano. Qual é a probabilidade de ocorrerem entre 15 e 25 alagamentos em um determinado ano?

Passo 1 — Verificar a condição de aproximação:

\[λ=20≥10\]

(Aproximação pela Normal válida.)

Passo 2 — Parâmetros da Normal equivalente:

\[μ=λ=20\]

\[σ=\sqrt{λ} = \sqrt{20} \approx4,472 \]

Passo 3 — Correção de continuidade:

\[P(15≤X≤25) discreta ⟶ P(14,5≤Y≤25,5) contínua.\] Passo 4 — Padronização:

\[Z_1 = \frac{14,5 - 20}{4,472} = \frac{-5,5}{4,472} \approx -1,230\]

\[Z_2 = \frac{25,5 - 20}{4,472} = \frac{5,5}{4,472} \approx 1,230\]

Passo 5 — Probabilidade:

\[P(15≤X≤25)≈Φ(1,230)−Φ(−1,230)=0,8907−0,1093=0,7814\]

Interpretação do engenheiro

Existem aproximadamente 78,1% de chance de o bairro registrar entre 15 e 25 alagamentos no ano. Esse tipo de análise embasa o dimensionamento de bacias de detenção e o planejamento de equipes de manutenção preventiva conforme a NBR 9649 (redes de esgoto) e diretrizes do Plano Diretor de Drenagem Urbana.

##  Introdução



A aproximação de distribuições discretas (como a Binomial e a Poisson) pela distribuição Normal (contínua) é um dos resultados mais elegantes e práticos da estatística. Esse fenômeno é fundamentado pelo Teorema Central do Limite (TCL) e pelo Teorema de de Moivre-Laplace.

Neste relatório, vamos entender como essas aproximações funcionam, as demonstrações matemáticas (usando Funções Geradoras de Momentos) e as aplicações práticas com a necessária correção de continuidade.

##  Por que usar a aproximação Normal?
Historicamente, antes dos computadores, calcular a distribuição Binomial $P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$ para um "n" grande era inviável. A Normal oferecia tabelas acessíveis. Hoje, a aproximação ainda é útil porque:
 
* Simplifica demonstrações teóricas em estatística inferencial;



* Fundamenta testes e intervalos de confiança (ex.: teste Z para proporções);



* Oferece intuição geométrica sobre a forma das distribuições;




* Em contextos de grande volume de dados, os resultados assintóticos valem plenamente.



* Sem a aproximação: É uma conta absurdamente longa (e que antigamente, antes dos computadores, era simplesmente impossível de fazer à mão).





* Com a aproximação Normal: Você calcula a média, o desvio padrão e faz uma única conta rápida usando a tabela Z (ou uma linha de código).









Em resumo, a medida que os parâmetros crescem 
$n→∞$ $ou$ $λ→∞$, tanto a Binomial quanto a Poisson "perdem" sua assimetria e se tornam indistinguíveis de uma curva Normal com mesma média e variância, uma manifestação elegante do Teorema Central do Limite.


## Teorema Central do Limite

O ponto de partida segundo @durrett2019 é o Teorema Central do Limite (TCL) ou Teorema do Limite Central(TLC), que afirma que a soma (ou média) de um grande número de variáveis aleatórias independentes e identicamente distribuídas tende a uma distribuição Normal, independentemente da distribuição original.

Dadas $n$ variáveis aleatórias independentes $X1,X2,…,Xn$, todas com a mesma distribuição, média $μ$ e variância $σ²$ finitas, a soma (ou média) dessas variáveis, quando $n→∞n$ converge em distribuição para uma Normal:



$$\bar{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$$
Equivalentemente, a variável padronizada:


$$Z_n = \frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1)$$
O resultado notável é que isso vale independentemente da distribuição original de cada $Xi$ — seja ela discreta, contínua, assimétrica ou multimodal.

Algumas condições para que Teorema do Limite Central (TLC) possa ser aplicado: 


   
   * As variáveis devem ser independentes entre si.
  
 
   * Cada variável deve ter média $μ$ e variância $σ²$ finitas.
 
 
 
  * O número de observações $n$ deve ser suficientemente grande, em geral $n≥30$ é uma regra prática, embora isso dependa da forma da distribuição original.


Conforme somamos mais variáveis aleatórias independentes, a distribuição da soma vai se "suavizando" e se tornando cada vez mais simétrica e em forma de sino — a curva normal. Distribuições muito assimétricas exigem um nn
n maior para que a aproximação seja boa.


O Teorema Central do Limite (TCL) justifica o uso generalizado da distribuição normal em estatística:

  * Inferência estatística: médias amostrais são aproximadamente normais para amostras grandes, o que sustenta intervalos de confiança e testes de hipótese.
  * Controle de qualidade: médias de processos produtivos seguem distribuições aproximadamente normais.
  * Ciências naturais e sociais: fenômenos que resultam da soma de muitos fatores independentes tendem a ser normalmente distribuídos (altura, erros de medição, etc.).




## Aproximação da distribuição Binomial à Normal


A distribuição binomial $B(n,p)$ descreve o número de sucessos em $n$ ensaios independentes, cada um com probabilidade $p$ de sucesso. Quando $n$ é suficientemente grande, calcular probabilidades binomiais exatas torna-se trabalhoso — o fatorial de números grandes é computacionalmente custoso. É nesse contexto que surge a aproximação pela distribuição normal: pelo Teorema Central do Limite, a soma de muitas variáveis aleatórias independentes e identicamente distribuídas tende a uma distribuição normal, e a binomial é exatamente isso — a soma de 
$n$ variáveis de Bernoulli. Assim, para
$n$ grande, $B(n,p)$ se comporta como uma normal $N(μ,σ2)$, com média $μ=np$ e desvio padrão $σ$:

$$\sigma = \sqrt{np(1-p)}$$
  

Para aplicar a aproximação, a regra prática mais comum exige que $np≥5$ e $n(1−p)≥5$ — sendo que muitos autores preferem o critério mais conservador de $np≥10$ e $n(1−p)≥10$ para garantir boa precisão. Satisfeita essa condição, calcula-se $μ$ e $σ$, padroniza-se a variável com $Z=(X−μ)/σ$  e consulta-se a tabela da normal padrão. Como a binomial é discreta e a normal é contínua, recomenda-se aplicar a correção de continuidade:



Ao calcular $P(X=k)$ usa-se $P(k−0,5≤X≤k+0,5)$ para $P(X≤k)$, usa-se $P(X≤k+0,5)$ e para $P(X≥k)$ usa-se $P(X≥k−0,5)$. Essa correção reduz o erro introduzido pela transição do discreto para o contínuo.


A qualidade da aproximação depende diretamente de $n$ e de quão próximo $p$ está de $0,5$. Quando $p$ é próximo de $0,5$, a binomial já é simétrica e a curva normal se ajusta bem mesmo para nn
n moderados. Quando $p$ é extremo — próximo de $0$ ou de $1$ — a binomial é muito assimétrica e são necessários valores de $n$ muito maiores para que a aproximação seja adequada.




Nesses casos extremos, pode ser preferível usar a aproximação de Poisson (para um $p$ pequeno e $n$ grande) em vez da normal. No geral, a aproximação normal é uma ferramenta poderosa e prática, amplamente usada em inferência estatística, intervalos de confiança e testes de hipóteses para proporções.

## Aproximação da distribuição de Poisson à Normal


A distribuição de Poisson $P(λ)$ modela o número de ocorrências de um evento em um intervalo fixo de tempo ou espaço, onde $λ$ representa a taxa média de ocorrências. Para valores pequenos de $λ$, a distribuição é assimétrica e os cálculos exatos são viáveis. Porém, à medida que $λ$ cresce, a distribuição vai se tornando cada vez mais simétrica e com formato de sino — exatamente o comportamento de uma normal. Isso ocorre porque a Poisson pode ser interpretada como a soma de muitas variáveis aleatórias independentes de Poisson com taxas pequenas, e pelo Teorema Central do Limite (TCL) essa soma converge para uma distribuição normal. Assim, para $λ$ suficientemente grande, $P(λ)$ se comporta como $N(μ,σ²)$, com a elegante propriedade de que média e variância coincidem: $μ=λ$ e $σ²=λ$.

Para aplicar a aproximação, a condição geralmente exigida é $λ≥10$ — quanto maior $λ$, melhor o ajuste. Com essa condição satisfeita, calcula-se $μ=λ$ e $σ=λ$, padroniza-se com $Z=(X−λ)/λ$ e consulta-se a tabela da normal padrão. 



Assim como na aproximação da binomial, aplica-se a correção de continuidade, pois a Poisson é discreta e a normal é contínua: para 
$P(X=k)$ usa-se $P(k−0,5≤X≤k+0,5)$; para $P(X≤k)$; usa-se $P(X≤k+0,5)$; e para $P(X≥k)$; usa-se $P(X≥k−0,5)$. Essa correção melhora consideravelmente a precisão, especialmente para $λ$ próximo do limiar mínimo.



A grande vantagem prática dessa aproximação está na simplificação dos cálculos: probabilidades acumuladas de Poisson para $λ$ grande envolvem somas de muitos termos com exponenciais e fatoriais, enquanto a normal reduz tudo a uma única padronização e consulta de tabela. A aproximação é especialmente útil em áreas como epidemiologia (número de casos de uma doença), telecomunicações (chegada de chamadas em uma central), controle de qualidade (defeitos por unidade produzida) e física (decaimento radioativo). Vale lembrar que, diferentemente da binomial, a Poisson não tem um nn
n explícito — a aproximação depende exclusivamente do valor de $λ$, o que torna o critério de validade ainda mais simples de verificar.

$X∼P(λ=25)$

**Obs: Calcular isso exatamente exigiria somar 11 termos com exponenciais e fatoriais grandes. Usamos a aproximação normal.**


**Passo 2 — Verificar a condição de validade:**



$$λ=25≥10$$
**(Satisfaz)**

**Passo 3 — Calcular a média μ e desvio padrão σ:**

$$μ=λ=25$$
$$\sigma = \sqrt{λ}$$
$$\sigma = \sqrt{25}$$
$$\sigma = 5 $$

Como queremos $P(20≤X≤30)$, expandimos meio ponto em cada extremo:

$$=P(−1,10≤Z≤1,10)$$

O valor exato pela Poisson é ≈72,4% — a aproximação ficou a menos de 0,5 ponto percentual do valor real, demonstrando excelente precisão.

 Existe aproximadamente 3,0% de chance de mais de 25 corpos de prova não serem adequados. Segundo a ABNT NBR 12655, se essa probabilidade ultrapassasse 10% seria um sinal de alerta para revisão do traço do concreto — neste caso, o lote está dentro do aceitável.

```{r}
#  de Concreto (ABNT NBR 12655)

#  Pergunta: P(X > 25) = ?

# --- Parâmetros do problema ---------------------------------
n <- 150

cat("n(1-p)=", n * (1 - p), ifelse(n * (1 - p) >= 5, "≥ 5 ✓", "< 5 ✗"), "\n\n")

mu    <- n * p
sigma <- sqrt(n * p * (1 - p))

cat("=== Parâmetros da Normal ===\n")

cat("σ = √(np·q)   =", round(sigma, 4), "\n\n")

# P(X > 25) discreta  →  P(Y > 25.5) contínua
limite <- 25.5

cat("Limite com correção de continuidade: ", limite, "\n")

    "=", round(Z, 4), "\n\n")

prob_normal <- pnorm(limite, mean = mu, sd = sigma, lower.tail = FALSE)

cat("=== Resultado pela aproximação Normal ===\n")
cat("P(X > 25) ≈ P(Z >", round(Z, 4), ") =", round(prob_normal, 6),
```

### Aproximação da distribuição de Poisson à Normal

***Hidráulica urbana***


Em uma rede de drenagem urbana, o número de ocorrências de alagamentos em um bairro segue uma distribuição de Poisson com média de 20 alagamentos por ano. Qual é a probabilidade de ocorrerem entre 15 e 25 alagamentos em um determinado ano?

**Passo 1 — Verificar a condição de aproximação:**



$$λ=20≥10$$

***(Aproximação pela Normal válida.)***


**Passo 2 — Parâmetros da Normal equivalente:**


$$μ=λ=20$$


$$σ=\sqrt{λ} = \sqrt{20} \approx4,472 $$


**Passo 3 — Correção de continuidade:**

$$P(15≤X≤25) discreta ⟶ P(14,5≤Y≤25,5) contínua.$$
**Passo 4 — Padronização:**


$$Z_1 = \frac{14,5 - 20}{4,472} = \frac{-5,5}{4,472} \approx -1,230$$

$$Z_2 = \frac{25,5 - 20}{4,472} = \frac{5,5}{4,472} \approx 1,230$$

**Passo 5 — Probabilidade:**

$$P(15≤X≤25)≈Φ(1,230)−Φ(−1,230)=0,8907−0,1093=0,7814$$

***Interpretação do engenheiro***




Existem aproximadamente 78,1% de chance de o bairro registrar entre 15 e 25 alagamentos no ano. Esse tipo de análise embasa o dimensionamento de bacias de detenção e o planejamento de equipes de manutenção preventiva conforme a NBR 9649 (redes de esgoto) e diretrizes do Plano Diretor de Drenagem Urbana.
 

***Como resolver utilizando o Rstudio?***

```{r}
# ============================================================
#  Aproximação Poisson à Normal — Drenagem Urbana
#
#  Problema: X ~ Poisson(λ = 20) alagamentos/ano
#  Pergunta: P(15 ≤ X ≤ 25) = ?
# ============================================================

# --- Parâmetro do problema ----------------------------------
lambda <- 20

# --- Verificação da condição de aproximação ----------------
cat("=== Verificação da condição ===\n")
cat("λ =", lambda, ifelse(lambda >= 10, "≥ 10 ✓  aproximação válida\n\n",
                          "< 10  ✗  aproximação fraca\n\n"))

# --- Parâmetros da Normal equivalente ----------------------
mu    <- lambda
sigma <- sqrt(lambda)

cat("=== Parâmetros da Normal equivalente ===\n")
cat("μ = λ      =", mu, "\n")
cat("σ = √λ     =", round(sigma, 4), "\n\n")

# --- Correção de continuidade e padronização ---------------
# P(15 ≤ X ≤ 25) discreta  →  P(14.5 ≤ Y ≤ 25.5) contínua
lo_cc <- 15 - 0.5
hi_cc <- 25 + 0.5

Z1 <- (lo_cc - mu) / sigma
Z2 <- (hi_cc - mu) / sigma

cat("=== Padronização (com correção de continuidade) ===\n")
cat("Limite inferior: ", lo_cc, "  →  Z₁ =", round(Z1, 4), "\n")
cat("Limite superior: ", hi_cc, "  →  Z₂ =", round(Z2, 4), "\n\n")

# --- Probabilidade via Normal (aproximação) ----------------
prob_normal <- pnorm(hi_cc, mean = mu, sd = sigma) -
               pnorm(lo_cc, mean = mu, sd = sigma)

cat("=== Resultado pela aproximação Normal ===\n")
cat("P(15 ≤ X ≤ 25) ≈ Φ(", round(Z2,4), ") - Φ(", round(Z1,4), ")\n")
cat("               =", round(prob_normal, 6),
    "→", round(prob_normal * 100, 2), "%\n\n")

# --- Valor exato pela Poisson (para comparação) ------------
prob_exata <- ppois(25, lambda = lambda) - ppois(14, lambda = lambda)

cat("=== Valor exato pela Poisson ===\n")
cat("P(15 ≤ X ≤ 25) exato =", round(prob_exata, 6),
    "→", round(prob_exata * 100, 2), "%\n\n")

cat("=== Erro da aproximação ===\n")
cat("Diferença absoluta:", round(abs(prob_normal - prob_exata), 6), "\n")
cat("Erro relativo:     ",
    round(abs(prob_normal - prob_exata) / prob_exata * 100, 2), "%\n\n")

# --- Tempo de retorno (contexto de drenagem urbana) --------
cat("=== Análise complementar: tempo de retorno ===\n")
prob_excede <- 1 - ppois(25, lambda = lambda)
cat("P(X > 25) =", round(prob_excede * 100, 2), "%\n")
cat("Tempo de retorno T = 1/P(X > 25) =",
    round(1 / prob_excede, 1), "anos\n\n")

# ============================================================
#  Gráfico: Poisson (barras) + Normal (curva) + intervalo
# ============================================================
library(ggplot2)

# Suporte da Poisson
k_seq <- seq(max(0, floor(mu - 5 * sigma)), ceiling(mu + 5 * sigma))

pois_df <- data.frame(
  k    = k_seq,
  prob = dpois(k_seq, lambda = lambda),
  tipo = ifelse(k_seq >= 15 & k_seq <= 25, "intervalo", "fora")
)

# Curva Normal contínua
x_seq <- seq(mu - 5 * sigma, mu + 5 * sigma, length.out = 600)
norm_df <- data.frame(
  x = x_seq,
  y = dnorm(x_seq, mean = mu, sd = sigma)

# Área sombreada sob a Normal (entre os limites com correção)
area_df <- subset(norm_df, x >= lo_cc & x <= hi_cc)

ggplot() +

            aes(x = x, y = y),
            fill = "#85B7EB", alpha = 0.30) +

  # Barras da Poisson
  geom_col(data = pois_df,
           aes(x = k, y = prob, fill = tipo),
           width = 0.75, alpha = 0.75) +

    values  = c("intervalo" = "#185FA5", "fora" = "#B4B2A9"),

    name    = "Poisson(λ = 20)"
  ) +

  # Curva Normal
  geom_line(data = norm_df,
            aes(x = x, y = y, linetype = "N(μ, σ²)"),
            color = "#D85A30", linewidth = 1.2) +
  scale_linetype_manual(
    values = c("N(μ, σ²)" = "solid"),
    name   = NULL
  ) +

  # Linhas verticais nos limites (correção de continuidade)
  geom_vline(xintercept = c(lo_cc, hi_cc),
             color = "#993C1D", linetype = "dashed", linewidth = 0.7) +
  annotate("text", x = lo_cc - 0.3, y = max(norm_df$y) * 0.78,
           label = "14,5", color = "#993C1D", size = 3.2, hjust = 1) +
  annotate("text", x = hi_cc + 0.3, y = max(norm_df$y) * 0.78,
           label = "25,5", color = "#993C1D", size = 3.2, hjust = 0) +

  # Linha de μ
  geom_vline(xintercept = mu,
             color = "#444441", linetype = "dotted", linewidth = 0.7) +
  annotate("text", x = mu + 0.4, y = max(norm_df$y) * 1.01,
           label = paste0("μ = ", mu),
           color = "#444441", size = 3.2, hjust = 0) +

  # Anotação da probabilidade
  annotate("text", x = mu, y = max(norm_df$y) * 0.55,
           label = paste0("P(15 ≤ X ≤ 25)\n≈ ",
                          round(prob_normal * 100, 2), "%"),
           color = "#0C447C", size = 3.8, fontface = "bold", hjust = 0.5) +

  labs(
    title    = "Drenagem urbana — alagamentos anuais",
    subtitle = paste0(

      "  |  P(15 ≤ X ≤ 25) ≈ ", round(prob_normal * 100, 2), "%"
```
